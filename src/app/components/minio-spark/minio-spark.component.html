Introduction

In this practice i make a basic integration with minio and spark using k8s and helm. All the implementetion i'll show you was tested on cloud shell, this is completely free and you don't have to worry about the installation of docker, k8s or helm. Because these tools are already installed in your cloud shell machine. I left you the minio-spark repository on github.

I must to clarify that this practice is inspired in a youtube tutorial, that i modify lightly, and you can watch here.

I'll just follow the main and necessary commands, that let you replicate this practice, and explain the basic without dive a lot into the scripts content. So, let's do it!

Minio Setup

As i mention previously, cloud shell has already installed kubernetes, the first command you need to run is

Next, clone the github repository and in the root folder create an instance of minio, you need to use the three files in minio folder. But before it's necessary two little changes.

First, in the minio-prod.yml file assign a correct value for path, it must be a existing folder in your machine. Now, save changes and run:

Second, in the minio-secret.yml file the MINIO_ROOT_USER and MINIO_ROOT_PASSWORD are in base64 and are 'minio_user' and 'minio_password', respectively.

You can change by your own credentials running in the terminal.

After these settings, just create the namespace 'minio-prod' and then create your minio instance.

If all it's going well, there is a pod called minio and a service called minio-service. The minio-service has two ports, 9000 and 9090. The 9000 port gives access to minio backend and the 9090 port gives access to the minio console. In my case, the host provided by cloud shell is https://9090-cs-102581714513-default.cs-us-east1-dogs.cloudshell.dev/.

For the integration with spark, you need a secret key and create a bucket. So, open the console and log in

Create your first bucket, the mine will be orders.

Now, in your bucket upload a .csv or .json or wharever file you want. But to do it easy, use the example file company_sales.json, i let it in the folder data.

The last part of this section is create access and secret keys, i'll use it later to connect spark to the orders bucket and process the company_sales.json file.

Copy and save the keys.

Next, is moment to create a spark operator instance and send a spark job that connects to minio process the data.

  2. Change the spark job script. To get the minikube ip (the cluster host) and the service port just type. Don't forget paste the access and secret keys that you created in the previous section.
